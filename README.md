The new sampled-potential operator bounds use the actual block-diagonal grid matrix. A uniform bound on its nodal two-component operators bounds the full grid operator with the same constant, without a grid-size factor. Differences of the actual potential factors satisfy the corresponding bound, and the fixed Z contribution is included in the bound for the second split factor.

The ordered Cayley perturbation estimates compare two Hermitian potential factors with the same first factor. They accumulate `sum_j |k_j|` times the potential-operator difference and the comparison initial-state norm, while retaining arbitrary initial mismatch. The actual sampled-potential consumer translates this to physical L2 at grid times. If both runs start from the point samples of the same weighted Fourier state, the potential perturbation contribution is bounded by `sum_j |k_j| * delta * sqrt(2*pi) * ||a||`, uniformly in the grid. This bound is for the grid-time states; the same constant is not asserted for the quadratic paths between grid times.

Symmetric finite Fourier cutoff preserves potential regularity and Hermitian symmetry. The difference from the full potential is bounded by exactly its omitted coefficient norm tail, which is at most its original weighted absolute moment divided by `(1+R)^2`. Substituting this actual tail into the sampled trajectory comparison gives a grid-independent potential-truncation error budget over bounded accumulated time. It compares the actual two numerical trajectories and does not assume a small residual or identify either trajectory with the PDE solution by itself.

Earlier initialization results remain unchanged: the actual sampled initial field has physical L2 interpolation error at most `2 * sqrt(2*pi) * ||a|| / (1+M)^2`, tends to zero on the explicit expanding odd grids, and retains arbitrary additional numerical initialization mismatch. The accepted alias, stencil, target-binding and grid-time/partial-slab residual certificates also retain their previous scope. Uniform control of the evolving numerical Fourier tails and fourth-frequency moments, and the remaining spatial/time refinement argument, are not supplied by this potential comparison. Full solver convergence or a general variable-potential refinement rate is not claimed.

## What each record establishes

A Git commit identifies repository bytes. Lean acceptance establishes elaboration of specified source under its inputs. An NDEA receipt records the specified checks and their input/output hashes. Independent qualification repeats the check in the documented isolated environment. These are different claims.

The manifest records accepted source and receipt hashes without changing sealed evidence. After publication, an external readback receipt must bind the actual Git commit/tree to this manifest's SHA-256 and every staged file hash. This yields commit → source → acceptance receipt and receipt → source hash → committed path without a self-hash cycle. No commit ID is invented inside its own content. Tags or releases can later mark a fully qualified milestone after review; never move a published verified tag.

Commit after meaningful source progress, before risky refactors, and at accepted milestones. Push at useful milestones; local recovery snapshots remain frequent. Changes to mathematics or tooling require new checks and new receipts in a working experiment, preserving this accepted baseline.
